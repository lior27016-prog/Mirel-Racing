## תכונות
- 4 מכוניות שונות
- יריבי AI עד 4
- 3 רמות קושי
- מינימאפ + מד מהירות
- טבלת שיאים

## 🎮 צ'יטים

**איך פותחים את תפריט הצ'יטים:**
- מקלדת: מקלידים `CHEATS` בכל רגע (עובד גם בפריסת מקלדת עברית)
- נייד: 5 לחיצות מהירות על הלוגו בתפריט הראשי, או על הכותרת "השהיה" באמצע מירוץ

אפשר גם להקליד כל קוד ישירות במקלדת בזמן המירוץ.

| קוד | מה הוא עושה |
|---|---|
| `TURBO` | מהירות ותאוצה ×1.6 |
| `GHOST` | עובר דרך מכוניות אחרות |
| `GRIP` | אין האטה מחוץ למסלול |
| `AUTOPILOT` | המכונית נוהגת לבד |
| `FREEZE` | היריבים נעצרים |
| `SLOWMO` | היריבים בחצי מהירות |
| `RAINBOW` | מכונית בצבעי הקשת |
| `GIANT` / `TINY` | מכונית ענקית / זעירה |
| `LAPSKIP` | מוסיף סיבוב אחד מיד (חד-פעמי) |
| `WINNER` | מסיים את המירוץ במקום 1 (חד-פעמי) |

צ'יטים שמופעלים נשמרים בין משחקים. ניקוד שהושג עם צ'יטים מסומן ב-🎮 בטבלת הדירוג.
