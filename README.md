# 🏎️ Mirel Racing

משחק מכוניות ברמה גבוהה עם פיזיקה מתקדמת, יריבים בינה מלאכותית, וטבלת דירוג.

## 🎮 כיצד לשחק

### בקרות
- **W / חץ למעלה** - תאוצה
- **S / חץ למטה** - בלימה/גיבוב לאחור
- **A / חץ שמאלה** - פניה שמאל
- **D / חץ ימין** - פניה ימין
- **P / כפתור השהה** - השהה משחק

### טלפון סלולרי
- **עיגול שמאל** - הנע את האצבע לשמאל/ימין להנעת הגה
- **עיגול ימין** - הנע את האצבע למעלה לתאוצה או למטה לבלימה

## 🎯 מטרה

השלם 3 סיבובים על המסלול בהר הפחות זמן!

## 🏁 תכונות

- **פיזיקה מתקדמת**: הנעת מנוע, בלימה, חיכוך, וטורק
- **יריבים חכמים**: 4 רמות קושי עם AI בינה מלאכותית
- **מסלול דינמי**: מסלול בצורת 8 עם חסמים ונקודות בדיקה
- **מערכת ניקוד**: שמור את הניקודים הטובים ביותר שלך
- **טבלת דירוג**: ראה את הניקודים המובילים
- **מינימפה**: ראה את מיקום כל המכוניות
- **תמיכה בטלפון סלולרי**: שחק בכל מכשיר

## 🎮 רמות קושי

### קל
- יריבים אטיים
- זמן תגובה ארוך
- ניהול מהירות בטוח

### בינוני (ברירת מחדל)
- יריבים מאתגרים
- זמן תגובה סביר
- משחק מאוזן

### קשה
- יריבים מהירים מאוד
- זמן תגובה מהיר
- הימנעות מתקדמת

## 📁 מבנה הפרויקט

```
mirel-racing/
├── index.html      # הדף הראשי
├── styles.css      # עיצוב הממשק
├── game.js         # לוגיקת המשחק
├── physics.js      # מנוע הפיזיקה
├── ai.js           # AI יריבים
├── input.js        # עיבוד קלט משתמש
└── README.md       # תיעוד זה
```

## 🛠️ טכנולוגיות

- **HTML5 Canvas** - רינדור גרפיקה
- **Vanilla JavaScript** - לוגיקת המשחק
- **CSS3** - עיצוב ממשק
- **LocalStorage** - שמירת ניקודים

## 🚀 להתחיל

1. פתח את `index.html` בדפדפן
2. לחץ על "התחל משחק"
3. בחר את רמת הקושי שלך
4. בחר את מספר היריבים
5. מירוץ!

## 🎨 קאסטומיזציה

אתה יכול לשנות את הדברים הבאים בקוד:

- **מספר סיבובים**: ערוך `this.maxLaps` ב-`game.js`
- **קושי AI**: ערוך את הפרמטרים ב-`ai.js`
- **עיצוב מכוניות**: ערוך את פונקציית `render` ב-`physics.js`
- **צבעים**: ערוך את ערכי ה-CSS ב-`styles.css`

## 💡 טיפים למשחק

1. **גזור סיבובים**: נסה לנסוע קרוב לאמצע המסלול
2. **בלימה תכנונית**: בלום קודם לעקומה כדי לשמור על שליטה
3. **הימנעות**: הימנע מיריבים כדי לשמור על מהירותך
4. **קו סיום**: עבור את קו ההתחלה כדי להשלים סיבוב
